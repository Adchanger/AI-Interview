# AI-Interview

AI 方向知识点整理与面试准备仓库。

## 内容规划

涵盖 AI 方向的常见知识点，包括但不限于：

- 机器学习基础（经典算法、模型评估、特征工程）
- 深度学习（CNN / RNN / Transformer、优化器、正则化）
- 大语言模型（LLM 原理、Prompt Engineering、RAG、Agent、微调）
- 多模态（视觉、语音、图文理解）
- 工程实践（训练与推理优化、部署、评测）
- 经典面试题与手撕代码

> 内容逐步补充中，欢迎补充与交流。
