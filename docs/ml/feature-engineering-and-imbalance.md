# 特征工程与类别不平衡（ML 八股 06）

> **更新时间**：2026-08-31

> **标签**：特征工程、归一化、类别不平衡、SMOTE、面试八股

> **一句话**：特征工程的核心是"把信息以模型能吃的形式喂进去"——归一化解决量纲、编码解决类别、分箱解决非线性、筛选解决冗余；类别不平衡则从**数据层（采样）、算法层（加权/损失）、评估层（指标与阈值）**三个层面一起治。

> **关联阅读**：[[/docs/ml/model-evaluation-metrics.md]]、[[/docs/ml/tree-ensemble-gbdt-xgboost.md]]

---

## 1. 数值特征处理

### 1.1 归一化 / 标准化

| 方法 | 公式 | 适用 |
|------|------|------|
| Min-Max 归一化 | $\frac{x-\min}{\max-\min}$ | 需要固定值域（图像像素、神经网络输入）；对离群值敏感 |
| **Z-score 标准化** | $\frac{x-\mu}{\sigma}$ | 默认选择，假设近似正态 |
| RobustScaler | $\frac{x-\text{median}}{IQR}$ | 有离群值时更稳 |
| Log / Box-Cox / Yeo-Johnson | $\log(1+x)$ 等 | 长尾右偏特征（金额、时长、点击数） |
| L2 归一化（按样本） | $x/\|x\|_2$ | 文本 TF-IDF、向量检索（配余弦相似度） |

> 面试高频：**哪些模型需要归一化？**
> - **需要**：所有基于**距离/内积**的（KNN、KMeans、SVM、PCA）、基于**梯度下降**的（LR、神经网络）、带 **L1/L2 正则**的线性模型；
> - **不需要**：**树模型**（决策树、RF、GBDT、XGB、LGBM）——只比较阈值，单调变换不影响分裂；朴素贝叶斯。

**关键工程纪律**：统计量（$\mu,\sigma,\min,\max$）**只能在训练集上 fit**，再 transform 验证/测试集；否则是数据泄漏。

### 1.2 分箱（离散化）

- 等宽 / 等频 / 基于卡方（ChiMerge）/ 基于决策树 / 业务规则；
- 好处：引入**非线性**、抗离群、可解释（评分卡）、稀疏化后配 LR 极快；
- 代价：信息损失、边界处不连续；
- 风控标配：分箱 + **WOE 编码** + IV 值筛选，$\mathrm{WOE}_i=\ln\frac{\text{坏样本占比}_i}{\text{好样本占比}_i}$，$\mathrm{IV}=\sum(\text{坏占比}-\text{好占比})\cdot\mathrm{WOE}$。

### 1.3 缺失值

| 策略 | 说明 |
|------|------|
| 删除 | 缺失率极高（>80%）或随机缺失且样本充足 |
| 统计填充 | 均值/中位数/众数；配一个 `is_missing` 指示列，别丢掉"缺失本身是信息"这件事 |
| 模型填充 | KNN / 迭代回归（MICE） |
| 原生支持 | XGBoost / LightGBM 学习默认方向；CatBoost 同理 |
| 特殊值 | 树模型可填 -999 让其自然分到一侧 |

## 2. 类别特征编码

| 方法 | 说明 | 风险 |
|------|------|------|
| One-Hot | 低基数（<10）首选；线性模型必备 | 高基数导致维度爆炸、稀疏 |
| Ordinal / Label | 有序类别（学历、评级） | 无序类别会引入虚假大小关系（树模型可容忍） |
| **Target / Mean Encoding** | 用该类别的标签均值替代 | **目标泄漏**，必须用 K 折 OOF + 平滑：$\frac{n\bar y_c + m\bar y}{n+m}$ |
| Frequency / Count | 用出现频次编码 | 简单有效，尤其是高基数 ID |
| Hash Trick | 哈希到固定维度 | 冲突不可逆，适合超高基数在线场景 |
| Embedding | 神经网络学习稠密表示 | 需足够样本；推荐系统标配 |
| CatBoost 有序 TS | 按时间顺序只用"过去"的统计量 | 解决泄漏与预测偏移 |

## 3. 特征选择与降维

| 类别 | 方法 | 说明 |
|------|------|------|
| **Filter**（过滤） | 方差阈值、卡方、互信息、相关系数、IV | 快，与模型无关；只看单变量易漏交互 |
| **Wrapper**（包裹） | 前向/后向搜索、RFE | 贴合模型但贵 |
| **Embedded**（嵌入） | L1 正则、树的特征重要性 | 训练即选择，性价比最高 |
| 降维 | PCA/SVD/UMAP | 生成新特征、损失可解释性，见 [[/docs/ml/unsupervised-clustering-and-dimensionality.md]] |

> 面试高频：**特征重要性能直接当特征选择依据吗？** → 需谨慎。基于不纯度的重要性对**高基数/连续**特征有偏，且共线特征会互相稀释；更可靠的是 **permutation importance** 或 **SHAP**，并结合稳定性（多折是否一致）。

### 3.1 高相关/共线特征

线性模型下共线导致系数不稳定、符号反转（可解释性崩坏）→ 用 VIF 检测（>10 需处理）、用 L2/PCA 缓解；树模型对共线不敏感但会稀释重要性。

## 4. 类别不平衡

### 4.1 三层治法

**① 数据层**

| 方法 | 要点 | 风险 |
|------|------|------|
| 随机下采样多数类 | 快，配 **Bagging/EasyEnsemble** 多次采样集成可挽回信息损失 | 丢信息 |
| 随机上采样少数类 | 简单 | 重复样本导致过拟合 |
| **SMOTE** | 在少数类样本与其 k 近邻之间**线性插值**造新样本 | 可能在类边界造噪声；高维/类簇重叠时失效；只能对**连续特征**做，类别特征需 SMOTE-NC |
| Borderline-SMOTE / ADASYN | 只在边界或困难区域生成 | 对噪声更敏感 |
| 欠采样清洗 | Tomek Links、ENN 去边界噪声 | 与上采样组合（SMOTE+Tomek） |

**关键纪律**：**采样只能在训练集内做**，且必须在交叉验证的每一折内部做（先划分再采样），否则合成样本泄漏到验证集，指标虚高。

**② 算法层**

- **类别权重 / 代价敏感**：`class_weight='balanced'`（$w_c = N/(K\cdot N_c)$）、XGBoost 的 `scale_pos_weight = #neg/#pos`；
- **Focal Loss**：$-(1-p_t)^\gamma\log p_t$，降低易分样本权重，检测领域标配，见 [[/docs/dl/loss-functions.md]]；
- **异常检测视角**：正样本极稀（<0.1%）时，改用 One-Class SVM / Isolation Forest / AutoEncoder 重构误差；
- **集成**：BalancedRandomForest、RUSBoost、EasyEnsemble。

**③ 评估层**

- 弃用 accuracy，改用 **PR-AUC / F1 / F2 / Recall@固定精确率 / KS**；
- **调阈值**往往比改模型更划算：先训一个概率校准良好的模型，再按业务代价选阈值；
- 采样后**概率需还原**：$p = \frac{p_s}{p_s+(1-p_s)/r}$（$r$ 为负样本采样率）。

> 面试高频：**不平衡一定要采样吗？** → 不一定。只要评估指标选对、阈值调好，很多时候**加权 + 阈值调整**优于采样（不改变数据分布、不引入合成噪声）。采样的主要收益是加速训练（下采样）和缓解极端稀疏梯度。

## 5. 数据泄漏（Leakage）自查清单

1. 归一化/编码统计量用了全量数据 → 必须只用训练集 fit；
2. 目标编码没做 OOF → 泄漏；
3. 采样在划分之前 → 泄漏；
4. 时序问题用随机 K 折 → **穿越**，必须按时间切（前向验证 / 滑窗）；
5. 特征里含"未来信息"（如用最终还款状态派生的字段）→ 逻辑穿越；
6. 同一实体（同用户/同图像的增强版本）分散在训练和验证集 → 用 GroupKFold；
7. 用测试集反复调参 → 变相过拟合，应留独立 holdout。

## 6. 面试高频问题速查

1. **哪些模型需要归一化？** → 距离/内积类、梯度下降类、带正则的线性模型需要；树模型不需要。
2. **归一化和标准化的区别？** → Min-Max 压到固定区间、对离群敏感；Z-score 变成零均值单位方差，更通用。
3. **高基数类别怎么编码？** → 频次编码、目标编码（OOF+平滑）、哈希、embedding、LightGBM 原生类别特征。
4. **目标编码为什么危险？** → 用到了标签，未做 OOF 会泄漏，训练集指标虚高、线上崩。
5. **缺失值怎么处理？** → 看缺失机制（MCAR/MAR/MNAR）；统计填充 + 缺失指示列；树模型可原生处理；缺失本身常是强特征。
6. **样本不平衡怎么办？** → 三层：数据（采样/SMOTE）、算法（权重/Focal/异常检测）、评估（PR-AUC + 阈值）。
7. **SMOTE 的原理与缺陷？** → 少数类近邻间线性插值；缺陷是边界造噪、高维失效、不适用类别特征、不能在验证集上做。
8. **`scale_pos_weight` 怎么设？** → 约等于 负样本数/正样本数。
9. **下采样后概率偏高怎么修正？** → 按采样率做先验还原，或用 Isotonic/Platt 校准。
10. **怎么避免数据泄漏？** → 所有 fit 只用训练集、时序按时间切、目标编码走 OOF、同实体不跨集、采样在划分之后。
11. **特征工程还重要吗（大模型时代）？** → 表格/风控/推荐场景依然是核心竞争力；端到端深度模型主要替代了图像/文本上的手工特征。
