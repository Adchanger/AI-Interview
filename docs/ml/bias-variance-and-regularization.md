# 偏差方差、过拟合与正则化（ML 八股 01）

> **更新时间**：2026-08-31

> **标签**：偏差方差、过拟合、正则化、L1L2、面试八股

> **一句话**：泛化误差 = 偏差² + 方差 + 噪声，欠拟合是偏差大、过拟合是方差大；正则化（L1/L2）通过限制模型复杂度把方差换成一点偏差，从而降低总误差。

> **关联阅读**：[[/docs/interview/bagu-knowledge-map.md]]、[[/docs/ml/model-evaluation-metrics.md]]

---

## 1. 背景：为什么面试必考

几乎所有「模型效果不好怎么办」的问题，最终都会被追问回这一套框架：先判断是偏差问题还是方差问题，再选对应手段。答不清这一层，后面的调参经验都会显得像碰运气。

---

## 2. 偏差-方差分解

对回归问题、平方损失，泛化误差可分解为：

$$\mathbb{E}\big[(y - \hat f(x))^2\big] = \underbrace{\big(\mathbb{E}[\hat f(x)] - f(x)\big)^2}_{\text{偏差}^2} + \underbrace{\mathbb{E}\big[(\hat f(x) - \mathbb{E}[\hat f(x)])^2\big]}_{\text{方差}} + \underbrace{\sigma^2}_{\text{噪声}}$$

- **偏差（Bias）**：模型的期望预测与真实函数的差距 → 模型**假设空间不够**（欠拟合）；
- **方差（Variance）**：换一份训练集，模型预测的抖动程度 → 模型**对数据太敏感**（过拟合）；
- **噪声（Irreducible error）**：数据本身的不可约误差，是任何模型的下界。

> 面试高频：这个分解严格成立的前提是**平方损失**。0-1 损失下的分解形式不同（不是简单相加），面试时说"经典分解针对平方损失"更严谨。

### 2.1 复杂度与两者的关系

| 模型复杂度 | 偏差 | 方差 | 表现 |
|-----------|------|------|------|
| 太低（线性模型拟合非线性数据） | 高 | 低 | 训练误差和测试误差都高 → **欠拟合** |
| 合适 | 中 | 中 | 总误差最小 |
| 太高（深树、无正则的大模型） | 低 | 高 | 训练误差很低、测试误差高 → **过拟合** |

> 补充（现代认知）：深度学习中存在 **double descent**（双下降）现象——参数量超过插值点后，测试误差会再次下降，所以"模型越大越过拟合"在过参数化 + 正则/隐式正则条件下并不成立。这是很好的加分回答。

## 3. 过拟合与欠拟合

### 3.1 怎么判断

| 现象 | 诊断 |
|------|------|
| 训练误差高、验证误差也高、两者接近 | 欠拟合（高偏差） |
| 训练误差很低、验证误差明显更高（gap 大） | 过拟合（高方差） |
| 训练/验证都低 | 正常 |
| 验证误差 < 训练误差 | 检查数据泄漏、划分错误、dropout 造成的训练态偏差 |

实操上画 **学习曲线**（误差 vs 训练样本数）：两条线都平在高位 → 加数据没用，要加模型容量；两条线有大 gap 且验证线还在下降 → 加数据有用。

### 3.2 过拟合的解决手段（按性价比排序）

1. **加数据 / 数据增强**：最本质，直接降方差；
2. **正则化**：L2（weight decay）、L1、弹性网；
3. **早停**（early stopping）：在验证集拐点停，等价于一种隐式正则；
4. **降低容量**：减层减宽、树的 `max_depth` / `min_samples_leaf`、剪枝；
5. **Dropout / DropPath**（神经网络）：训练时随机置零，等价于集成大量子网络；
6. **集成**：Bagging / 随机森林通过平均降方差；
7. **交叉验证**：不是降过拟合的手段，而是**可靠地评估**是否过拟合、选超参；
8. **加噪声 / 标签平滑**：软化标签，避免对训练标签过度自信。

### 3.3 欠拟合的解决手段

加特征（含交叉特征）、换更强模型（核方法、GBDT、深网）、减小正则强度、训练更久、检查学习率是否过大导致没收敛。

## 4. L1 与 L2 正则化

优化目标：

$$\min_w \; L(w) + \lambda \Omega(w), \qquad \Omega_{L1}(w)=\|w\|_1,\;\; \Omega_{L2}(w)=\tfrac12\|w\|_2^2$$

### 4.1 为什么 L1 产生稀疏解（三种讲法，任选其一）

1. **几何视角**：L1 约束域是菱形（顶点在坐标轴上），损失等值线最先接触的往往是顶点 → 部分权重恰好为 0；L2 约束域是圆，接触点一般不在轴上 → 权重小但不为 0。
2. **梯度/次梯度视角**：L1 的惩罚梯度是常数 $\lambda \cdot \mathrm{sign}(w)$，无论 $w$ 多小都在往 0 推，能真正压到 0；L2 的梯度 $\lambda w$ 随 $w$ 变小而消失，只能无限接近 0。
3. **闭式解视角**：正交设计下 L1 的解是**软阈值** $\mathrm{sign}(\hat w)\max(|\hat w|-\lambda, 0)$，小于阈值直接归零；L2 的解是等比收缩 $\hat w/(1+\lambda)$。

### 4.2 贝叶斯视角

- L2 ↔ 权重的 **高斯先验**（MAP 估计）；
- L1 ↔ 权重的 **拉普拉斯先验**（尖峰厚尾，偏好 0）。

### 4.3 对比表

| 维度 | L1（Lasso） | L2（Ridge / weight decay） |
|------|-------------|---------------------------|
| 解的性质 | 稀疏，自带特征选择 | 稠密、整体收缩 |
| 可导性 | 0 点不可导（用次梯度 / 坐标下降 / 近端梯度） | 处处可导 |
| 共线性特征 | 随机保留其中一个 | 让共线特征平摊权重，更稳定 |
| 典型用途 | 高维特征筛选、可解释性 | 默认选择，提升数值稳定性 |
| 组合 | Elastic Net：$\alpha\|w\|_1 + \frac{1-\alpha}{2}\|w\|_2^2$，兼顾稀疏与稳定 | |

> 面试高频：**weight decay 和 L2 正则是一回事吗？** → 在 SGD 下等价；在 Adam 下不等价，因为 L2 项也会被自适应学习率缩放，所以有了 **AdamW**（解耦权重衰减）。细节见 [[/docs/dl/optimizers-and-lr-schedule.md]]。

### 4.4 是否正则化偏置项？

一般**不对 bias 和归一化层的 scale/shift 做 weight decay**：它们不控制函数复杂度，衰减它们只会破坏拟合能力。大模型训练脚本里常见的 `no_decay = ["bias", "LayerNorm.weight"]` 就是这个原因。

## 5. 从正则化到大模型时代

| 场景 | 主要正则手段 |
|------|-------------|
| 传统 ML | L1/L2、树剪枝、Bagging |
| CNN 时代 | 数据增强（翻转/裁剪/Mixup/CutMix）、Dropout、BN 的隐式正则 |
| Transformer / LLM 预训练 | weight decay(0.1 量级)、dropout（大规模预训练常设 0）、超大数据本身就是最强正则 |
| LLM 微调 | LoRA（低秩约束即容量约束）、更小 lr、更少 epoch（1–3）、混入通用数据防灾难性遗忘 |

> 面试高频：**为什么大模型预训练常把 dropout 关掉？** → 数据量远大于参数量的信息容量需求时，过拟合不是主要矛盾，dropout 反而降低有效容量与吞吐；微调阶段数据少，才重新开启 dropout / 用 LoRA 约束。

## 6. 面试高频问题速查

1. **偏差方差怎么分解？** → 平方损失下：偏差² + 方差 + 噪声；偏差来自模型假设不足，方差来自对训练集敏感。
2. **过拟合怎么判断？** → 训练误差远低于验证误差，学习曲线 gap 大。
3. **过拟合怎么解决？** → 加数据/增强、正则、早停、降容量、dropout、集成。
4. **L1 为什么稀疏？** → 菱形约束顶点 / 常数惩罚梯度 / 软阈值闭式解，三个角度任选。
5. **L1 与 L2 怎么选？** → 要特征选择或高维稀疏用 L1；默认稳定性用 L2；两者都要用 Elastic Net。
6. **正则化为什么能降过拟合？** → 限制有效假设空间（等价于给权重加先验），用少量偏差换较大方差下降。
7. **交叉验证的作用？** → 更可靠地估计泛化误差与选超参，不直接减少过拟合；小数据用 K 折，时序数据要用滑窗/前向验证避免穿越。
8. **dropout 训练与推理有什么区别？** → 训练随机置零并按 $1/(1-p)$ 缩放（inverted dropout），推理关闭；否则期望不一致。
9. **模型越大越容易过拟合吗？** → 经典结论如此，但过参数化 + 隐式正则下有 double descent，实践中大模型靠数据规模与正则控制。
10. **weight decay 与 L2 等价吗？** → SGD 等价，Adam 不等价 → AdamW。
