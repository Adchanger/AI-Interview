# 支持向量机 SVM（ML 八股 03）

> **更新时间**：2026-08-31

> **标签**：SVM、对偶问题、核函数、hinge loss、面试八股

> **一句话**：SVM 找的是"离两类样本最远"的超平面（最大间隔），通过拉格朗日对偶把问题变成只依赖样本内积的形式，从而能用核函数在隐式高维空间做非线性分类。

> **关联阅读**：[[/docs/ml/logistic-regression.md]]、[[/docs/ml/bias-variance-and-regularization.md]]

---

## 1. 硬间隔：最大间隔的由来

样本 $y_i\in\{-1,+1\}$，超平面 $w^\top x + b = 0$，点到平面距离 $\frac{|w^\top x_i+b|}{\|w\|}$。

固定尺度（令支持向量满足 $y_i(w^\top x_i+b)=1$）后，间隔为 $\frac{2}{\|w\|}$，最大化间隔 ⇔ 最小化 $\|w\|^2$：

$$\min_{w,b}\ \tfrac12\|w\|^2 \quad \text{s.t. } y_i(w^\top x_i + b)\ge 1,\ \forall i$$

这是一个**凸二次规划**（QP），有唯一全局最优。

> 面试高频：**为什么最大化间隔？** → 结构风险最小化：间隔越大，对应的假设空间 VC 维越小、泛化界越紧；直觉上决策边界离数据越远，对扰动越鲁棒。

---

## 2. 软间隔与 hinge loss

现实数据不可分/有噪声，引入松弛变量 $\xi_i\ge 0$：

$$\min_{w,b,\xi}\ \tfrac12\|w\|^2 + C\sum_i \xi_i \quad \text{s.t. } y_i(w^\top x_i+b)\ge 1-\xi_i,\ \xi_i\ge 0$$

消去 $\xi_i$ 得到**无约束形式**：

$$\min_{w,b}\ \tfrac12\|w\|^2 + C\sum_i \max\big(0,\ 1 - y_i(w^\top x_i + b)\big)$$

即 **L2 正则 + hinge loss**。

- $C$ 大 → 惩罚违反间隔重 → 间隔窄、易过拟合（低偏差高方差）；
- $C$ 小 → 允许更多违反 → 间隔宽、更平滑（高偏差低方差）；
- $C \to \infty$ 退化为硬间隔。

> 面试高频：**hinge loss 与 log loss 的区别？** → hinge 在间隔外损失恰为 0（稀疏、只有支持向量起作用），log loss 永远大于 0（所有样本都贡献梯度）；hinge 不可导于 1 点（用次梯度），log loss 处处可导且能输出概率。

## 3. 拉格朗日对偶

引入乘子 $\alpha_i\ge0$，对 $w,b$ 求偏导为 0 得 $w=\sum_i\alpha_i y_i x_i$、$\sum_i \alpha_i y_i = 0$，代回得对偶问题：

$$\max_{\alpha}\ \sum_i \alpha_i - \tfrac12\sum_{i,j}\alpha_i\alpha_j y_i y_j \langle x_i, x_j\rangle \quad \text{s.t. } 0\le\alpha_i\le C,\ \sum_i\alpha_i y_i = 0$$

### 3.1 为什么要转对偶（必背三点）

1. **能引入核函数**：目标函数只含样本**内积** $\langle x_i,x_j\rangle$，可直接换成 $K(x_i,x_j)$，实现隐式高维映射；
2. **复杂度从维度 d 转到样本数 N**：高维（甚至无穷维）特征下原问题不可解，对偶只需 $N\times N$ 的 Gram 矩阵；
3. **解具有稀疏性**：由 KKT 条件只有支持向量的 $\alpha_i>0$，预测只依赖少量样本。

### 3.2 KKT 条件与支持向量分类

| $\alpha_i$ | 含义 |
|-----------|------|
| $\alpha_i = 0$ | 间隔外的普通样本，对模型无影响（删掉也不变） |
| $0<\alpha_i<C$ | **恰在间隔边界**上的支持向量，$y_i f(x_i)=1$，可用来求 $b$ |
| $\alpha_i = C$ | 违反间隔的样本（$\xi_i>0$），落在间隔内或被错分 |

预测：$f(x)=\sum_{i\in SV}\alpha_i y_i K(x_i,x)+b$。

### 3.3 求解算法

标准 QP 复杂度太高（$O(N^3)$ 量级），实用算法是 **SMO**（Sequential Minimal Optimization）：每次挑两个 $\alpha$ 做解析优化（因为等式约束 $\sum\alpha_iy_i=0$ 至少要动两个），迭代到 KKT 满足。线性 SVM 大规模场景直接优化原问题更快（liblinear / Pegasos SGD）。

---

## 4. 核函数

核技巧：只要 $K(x,z)=\langle\phi(x),\phi(z)\rangle$ 存在，就无需显式计算 $\phi$。合法核的条件是 **Mercer 定理**：核矩阵对任意样本集都对称半正定。

| 核 | 表达式 | 说明 |
|----|--------|------|
| 线性 | $x^\top z$ | 高维稀疏（文本）首选，可解释、快 |
| 多项式 | $(\gamma x^\top z + r)^d$ | $d$ 大易过拟合、数值不稳 |
| **RBF / 高斯** | $\exp(-\gamma\|x-z\|^2)$ | 默认首选，对应无穷维特征空间 |
| Sigmoid | $\tanh(\gamma x^\top z + r)$ | 不总满足 Mercer，少用 |

**RBF 的 $\gamma$**：$\gamma$ 大 → 单个样本影响半径小 → 边界扭曲、过拟合；$\gamma$ 小 → 趋近线性、欠拟合。与 $C$ 一起网格搜索是标准做法。

> 面试高频：**核函数怎么选？** → 特征维度远大于样本数（文本、one-hot）用线性核；样本数适中、特征不多且非线性明显用 RBF；样本量特别大（>10 万）核 SVM 训练/推理都吃不消，改用线性 SVM 或 GBDT/神经网络。

---

## 5. 其他要点

- **SVM 需要归一化**：距离与核函数（RBF 里的 $\|x-z\|$）都对量纲敏感，**必须**标准化，这与 LR"可选"不同；
- **对缺失值敏感**：需要完整的特征向量算距离/核，缺失必须先填补；
- **多分类**：原生二分类，靠 OvO（libsvm 默认）或 OvR 扩展；
- **SVR（回归）**：用 $\epsilon$-不敏感损失，管道内误差不计；
- **One-Class SVM**：异常检测；
- **概率输出**：SVM 本身不输出概率，需 **Platt scaling**（在验证集上再训一个 sigmoid），代价是要额外交叉验证。

### 5.1 优缺点

**优点**：小样本高维表现好、有严格的凸优化与泛化理论、核技巧灵活、解稀疏、对边界外样本鲁棒。

**缺点**：训练复杂度约 $O(N^2)\sim O(N^3)$ 不适合大数据、核方法难并行、超参（$C,\gamma$）敏感、无概率输出、对缺失值和未归一化数据敏感、可解释性弱于 LR/树。

## 6. 面试高频问题速查

1. **SVM 的优化目标是什么？** → 最小化 $\frac12\|w\|^2 + C\sum\xi_i$，即最大间隔 + 容忍少量违反。
2. **为什么要转对偶问题？** → 引入核、复杂度转到样本数、解稀疏（三点必答）。
3. **支持向量是什么？** → $\alpha_i>0$ 的样本，只有它们决定超平面。
4. **C 和 γ 的作用？** → C 控制对违反间隔的惩罚（过拟合旋钮）；γ 控制 RBF 影响半径（同样是过拟合旋钮）。
5. **hinge loss 长什么样？** → $\max(0, 1-yf(x))$，间隔外为 0。
6. **SVM 与 LR 怎么选？** → 大规模稀疏 + 要概率 → LR；小样本非线性 + 要强边界 → 核 SVM。
7. **核函数的合法条件？** → Mercer 定理：核矩阵对称半正定。
8. **SVM 要归一化吗？** → 必须，因为核/距离对量纲敏感。
9. **SVM 能处理大规模数据吗？** → 核 SVM 不行（$N^2$ 级）；线性 SVM 可用 liblinear/SGD 处理百万级。
10. **SVM 怎么做多分类？** → OvO / OvR；libsvm 用 OvO 投票。
