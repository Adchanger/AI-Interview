## 一、基础概念

### Q1. 为什么 Transformer 需要位置编码？⭐⭐⭐

> **速答**：自注意力是**置换不变**的——把输入 token 顺序打乱，注意力输出只是行跟着换，模型感知不到"谁在前谁在后"。而语言严重依赖语序（"我打你" ≠ "你打我"），所以必须在输入侧显式注入位置信息。

**解析**：注意力只计算"两两 token 的相似度"，本质上是对一个**集合**（而非序列）做加权求和。并行的代价就是丢失顺序——位置编码是对这个代价的补偿。

**追问**：
- 那 CNN / RNN 需要位置编码吗？→ 不需要显式注入：RNN 顺序处理天然带时序，CNN 的卷积核本身有空间结构；只有注意力这种"集合操作"需要。
- 没有位置编码模型会怎样？→ 退化为 bag-of-words，语序、语法、长距离依存全部丢失。

**关联**：[[/docs/llm/positional-encoding.md]] §1、[[/docs/llm/transformer-principle.md]]

### Q2. 正余弦位置编码的公式是什么？为什么这么设计？⭐⭐⭐

> **速答**：偶数维用 sin、奇数维用 cos，频率按 $10000^{-2i/d}$ 指数递减，形成从高频到低频的多频组合。设计动机有三：无参数可外推（理论上）、每个位置编码唯一、$PE_{pos+k}$ 是 $PE_{pos}$ 的线性函数（相对位置可被线性表示）。

$$PE_{(pos,\,2i)} = \sin\!\left(\frac{pos}{10000^{2i/d}}\right),\qquad PE_{(pos,\,2i+1)} = \cos\!\left(\frac{pos}{10000^{2i/d}}\right)$$

**解析**：多频设计可以类比二进制计数——低位（高频维）随位置快速变化、高位（低频维）缓慢变化，组合起来保证大范围位置互不重复。sin/cos 成对出现，是为了用三角恒等式把"平移 $k$ 步"写成线性变换。

**追问**：实践中正余弦外推效果好吗？→ 不好。超出训练长度后高频维出现混叠、编码模式偏离训练分布，PPL 明显上升——"理论上可外推"不等于"实践上好外推"。

**关联**：[[/docs/llm/positional-encoding.md]] §2.1

### Q3. 为什么 token embedding 和位置编码可以直接相加？⭐⭐

> **速答**：两者同维，相加不引入参数、不改变序列长度；从线性代数看，"拼接后过线性层"与"分别投影再相加"等价（$\mathrm{concat}[x;pe]\,W = xW_1 + peW_2$）；且 sin/cos 值域有界（$[-1,1]$），不会淹没语义信息，模型能学会把两者分解到近似正交的子空间。

**追问**：
- 为什么不拼接？→ 拼接会把后续所有层的输入维度放大近一倍，参数量与计算量都涨；相加是零成本的融合。
- 相加不会互相干扰吗？→ 训练后 embedding 与 PE 倾向占据不同子空间；且各维度 PE 量级小且模式固定，干扰可被网络吸收。

**关联**：[[/docs/llm/transformer-principle.md]]

### Q4. 绝对位置编码和相对位置编码的本质区别？⭐⭐⭐

> **速答**：绝对编码回答"我在第几个"，相对编码回答"你离我多远"。语言结构本质依赖**相对关系**（"动词离主语近"），长度外推也要求模型对"没见过的距离"依然有效——没见过的绝对位置没法学，没见过的相对距离却可以泛化。

**解析**：

| 维度 | 绝对（正余弦、可学习） | 相对（T5 bias、RoPE、ALiBi） |
|------|----------------------|------------------------------|
| 注入对象 | token 自身表示 | token 两两之间的注意力关系 |
| 外推能力 | 差~一般 | 好（可插值进一步放大） |
| 代表模型 | BERT、GPT-2 | T5、LLaMA/Qwen（RoPE）、BLOOM（ALiBi） |

**关联**：[[/docs/llm/positional-encoding.md]] §3

### Q5. 可学习位置编码有什么缺点？⭐⭐

> **速答**：本质是查表——表的长度就是训练长度，**零外推能力**；参数随最大长度线性增长；相比函数式编码要吃更多数据才能学好。

**追问**：既然缺点明显，为什么 BERT / GPT-2 用它？→ 简单灵活、当时上下文短（512/1024），外推需求弱；且短文本任务上可学习编码表达力足够。

**关联**：[[/docs/llm/positional-encoding.md]] §2.2

## 二、RoPE 原理（核心必考）

### Q6. RoPE 的原理是什么？为什么旋转能实现相对位置？⭐⭐⭐

> **速答**：RoPE 把 Q/K 按二维一组做旋转，位置 $m$ 的旋转角为 $m\theta_i$（$\theta_i = \mathrm{base}^{-2i/d}$ 多频递减）。利用旋转矩阵性质 $R_m^\top R_n = R_{n-m}$，注意力内积 $(R_m q)^\top (R_n k) = q^\top R_{n-m} k$ **只依赖相对距离 $n-m$**——相对位置不是"加"进去的，而是旋转的几何性质自然涌现的。

**解析**（二维推导，白板必会）：

$$R_m = \begin{bmatrix} \cos m\theta & -\sin m\theta \\ \sin m\theta & \cos m\theta \end{bmatrix},\qquad R_m^\top R_n = R_{n-m}$$

$d$ 维向量拆成 $d/2$ 个互不耦合的二维平面，每个平面按自己的频率 $\theta_i$ 旋转——这就是"多频"的来源，与正余弦编码的频率设计一脉相承。

> 📌 配图待补：RoPE 旋转机制示意图（计划与 [[/docs/llm/positional-encoding.md]] §3.2 共用一张）

**追问**：
- 为什么按 2 维一组？→ 二维旋转是最小的旋转单元；$d$ 维空间的任意旋转可分解为 $d/2$ 个独立平面旋转，计算上是分块对角矩阵，代价极低。
- RoPE 要训练参数吗？→ 不要，base 是超参数（默认 10000），无学习参数。

**关联**：[[/docs/llm/positional-encoding.md]] §3.2

### Q7. RoPE 为什么只作用在 Q/K，不作用在 V？⭐⭐⭐

> **速答**：位置信息只需要影响"谁跟谁匹配"（注意力权重），不需要影响"匹配到了什么内容"。V 是被加权的载荷，如果对 V 也旋转，输出会混入绝对位置信息，且多个 V 加权平均时不同相位的旋转会互相干扰，破坏内容表示的平移一致性。

**解析**：注意力的职责分离——Q/K 决定**权重**（where to attend），V 决定**内容**（what to read）。位置是"where"的属性，所以只进 Q/K；这也保证了 $n-m$ 相同的任意位置对，注意力权重一致（相对性）。

**追问**：对输入 embedding 直接旋转行不行？→ 那就退回绝对编码了：旋转会跟着 token 表示流入所有后续层，污染语义子空间。

**关联**：[[/docs/llm/positional-encoding.md]] §3.2、§6

### Q8. RoPE 为什么能成为现代 LLM 的标配？⭐⭐⭐

> **速答**：四点——①相对位置语义，符合语言结构先验；②零额外参数；③只改 Q/K，不改变注意力结构，与 FlashAttention、KV Cache、GQA 等所有工程优化无缝兼容；④配合 NTK/YaRN 插值，长度外推上限最高。LLaMA、Qwen、GLM、Mistral、DeepSeek 全系采用。

**追问**：RoPE 完美吗？→ 不完美：直接外推仍会崩（见 Q10）；低频维承载长距离信息但分辨率有限（见 Q16）；与低秩压缩（MLA）不兼容，需要解耦（见 Q17）。

**关联**：[[/docs/llm/positional-encoding.md]] §3.2

### Q9. RoPE 的"远程衰减"性质是怎么回事？⭐

> **速答**：在 Q/K 近似随机的假设下可以推出：RoPE 内积的期望随相对距离增大而**振荡衰减**，形成"近大远小"的归纳偏置（类似 ALiBi 的软版本）。但这是**初始化偏置而非硬约束**——训练后模型可以学会让特定的头不衰减（如负责全局汇聚的头），所以不能把远程衰减当成严格性质来依赖。

**解析**：苏剑林在《Transformer 升级之路》系列中给出了期望衰减的推导；后续研究（如 Barbero et al., *Round and Round We Go*, 2024）进一步分析了旋转维度与注意力 sink 的相互作用，指出训练会重塑各头的距离偏好。

**追问**：这个性质有什么用？→ 解释了 RoPE 为什么自带局部性先验、训短序列也能学到稳定的注意力模式；也是 StreamingLLM 类滑窗方案能 work 的部分原因。

**关联**：[[/docs/llm/positional-encoding.md]] §3.2

## 三、长度外推（进阶高频）

### Q10. RoPE 直接外推为什么会崩？⭐⭐⭐

> **速答**：训练只见过长度 $L_{\text{train}}$ 内的旋转角；外推时**低频维**（周期长，训练时连一个周期都没转完）的相位第一次进入未见区间，注意力 logits 分布漂移 → PPL 爆炸。崩溃的根源在低频维，不是高频维。

**解析**：$\theta_i = \mathrm{base}^{-2i/d}$，$i$ 越大频率越低、波长越长。波长超过 $2\pi L_{\text{train}}$ 的维度，训练时相位只覆盖了一个小角度区间；推理长度翻倍，这些维度就进入"相位无人区"。

**追问**：高频维为什么不怕外推？→ 高频维在训练时已转过许多个完整周期，相位分布被充分覆盖，新位置的相位落在已见分布内。

**关联**：[[/docs/llm/long-context-and-flashattention.md]] §3.1

### Q11. 位置内插（PI）的原理与代价？⭐⭐⭐

> **速答**：把推理时的位置 $m$ 线性压缩为 $m/s$（$s$ = 扩展倍数），所有位置压回训练区间，再少量微调即可（原论文报告约 1000 步）。代价是**位置分辨率下降**：相邻 token 的相位差缩小 $s$ 倍，模型区分邻近位置的能力变弱。

**解析**：PI（Chen et al. 2023, Meta）的直觉是"模型只学过 $[0, L_{\text{train}}]$ 内的位置，那就别让任何位置出界"。但线性压缩一视同仁地对待所有频率——高频维的局部细节被压没了，这正是 NTK/YaRN 要改进的点。

**追问**：直接外推、PI 免训练、PI 微调的效果排序？→ 直接外推（崩）≪ PI 免训练（可用但掉点）< PI 微调（好）< YaRN 微调（更好）。

**关联**：[[/docs/llm/long-context-and-flashattention.md]] §3.2

### Q12. NTK-aware 与 Dynamic NTK 是什么原理？⭐⭐⭐

> **速答**：不动位置、改 base：把 RoPE base 按扩展倍数放大（社区推导的缩放为 $\mathrm{base}' = \mathrm{base}\cdot s^{d/(d-2)}$），等效于"**高频维保持外推、低频维多插值**"，把外推压力平摊到所有频率上。苏剑林的进制类比：多频编码像一个 $\theta$ 进制计数器——直接外推把压力全压在高位，线性内插让低位过密，NTK 缩放相当于"进制转换"，每位均匀分担。Dynamic NTK 进一步按当前实际推理长度动态计算缩放比，可免训练（Qwen 等推理框架内置）。

**解析**：与 PI 的对比是核心考点——PI 压缩**位置**（所有频率同等受损），NTK 缩放**频率**（高频少动、低频多压），保留了局部分辨率，因此免训练效果远好于 PI 免训练。

**追问**：免训练外推的极限在哪？→ 免训练通常只能撑 2~4 倍扩展且长程检索能力（NIAH）下降明显；要上 128k+ 仍需长上下文继续训练。

**关联**：[[/docs/llm/long-context-and-flashattention.md]] §3.2

### Q13. YaRN 相比 NTK 改了什么？⭐⭐⭐

> **速答**：两个改进——①**NTK-by-parts**：按"维度波长 vs 上下文长度"的比值把频率分三组：波长远超上下文的低频维做线性内插、波长远短于上下文的高频维不外插、中间维度斜坡平滑过渡，比 NTK 的连续缩放更精细；②**注意力温度修正**：内插会把注意力 logits 压平（熵增大），对 Q/K 乘一个温度因子（$\sqrt{1/t} \approx 0.1\ln s + 1$）补回锐度。论文报告只需约 1/10 的 token、1/2.5 的步数微调，效果优于 PI 与 NTK，是 Mistral/Qwen 长上下文版本的主流方案。

**解析**：YaRN（Peng et al. 2023）的关键洞察是"不同波长区间该用不同策略"，并用温度修正解决了一个此前被忽视的问题：插值改变了 logits 的尺度分布，即使位置对了，注意力也会变"钝"。

**追问**：YaRN 微调需要多大数据量？→ 论文报告约为 PI 的 1/10 token 数（如 64k 上下文用几十亿 token 量级），是它能成为工业标准的关键。

**关联**：[[/docs/llm/long-context-and-flashattention.md]] §3.2

### Q14. 调大 RoPE base 为什么能扩展上下文？⭐⭐

> **速答**：调大 base 等价于整体降低旋转频率、拉长各维波长——同样的目标长度下，低频维相位更不容易越出训练区间。例如 LLaMA-3 把 base 从 1e4 提到 5e5（配合长上下文继续训练）支持 8k，Code Llama 用 1e6 支持 100k。注意：**必须配合继续训练**，免训练直接调大 base 会损害短距离位置分辨。

**追问**：调大 base 和 YaRN 冲突吗？→ 不冲突，可调大 base 继续训练后再叠加 YaRN 类插值进一步外推，两者作用在不同阶段。

**关联**：[[/docs/llm/long-context-and-flashattention.md]] §3.2

### Q15. 高频维和低频维的分工是什么？为什么外推方法要区别对待？⭐⭐

> **速答**：维度 $i$ 小 → $\theta_i$ 大 → 波长短（高频），编码**局部、细粒度**相对位置；$i$ 大 → 波长长（低频），编码**远程、粗粒度**位置。所有外推方法的本质都在调和一对矛盾：低频维容易相位越界（要压），高频维被压缩会损失局部分辨率（要保）。NTK 的"高频外推、低频内插"、YaRN 的按波长分组，都是这对矛盾的不同解法。

**解析**：这道题是把 Q10–Q14 串起来的"元问题"，面试官常用它判断你是背了名词还是理解了机制。

**关联**：[[/docs/llm/positional-encoding.md]] §3.2

## 四、方案对比与工程实践

### Q16. RoPE 和 ALiBi 怎么对比？⭐⭐⭐

> **速答**：RoPE 把相对位置以**乘法（旋转）**编进 Q/K，ALiBi 以**加法线性偏置**（$\text{score} - m\cdot|i-j|$）加在注意力分数上。ALiBi 零参数、训短测长开箱即用，但线性惩罚对远距离关系过于僵硬（"远处再重要也衰减"），超长上下文表达弱于 RoPE；RoPE 兼容 FlashAttention、配合插值外推上限更高，是当前绝对主流，ALiBi 主要用于 BLOOM 等早期模型。

**追问**：
- ALiBi 的斜率 $m$ 怎么定的？→ 每个头一个固定斜率，按几何数列 $2^{-8/h}$ 间隔分布（不训练），深斜率的头关注局部、浅斜率的头兼顾远程——也是一种"多频"设计。
- 两者能混用吗？→ 可以（叠加偏置），但主流实践没有这么做的必要。

**关联**：[[/docs/llm/positional-encoding.md]] §3.3

### Q17. RoPE 与 GQA / MLA 兼容吗？⭐⭐

> **速答**：与 GQA/MQA 天然兼容——RoPE 只作用在 Q/K 上，与 KV 头数无关。但与 MLA 的"矩阵吸收"不兼容：RoPE 旋转不能穿透低秩投影矩阵（$R\,W\,c \neq W'\,c$），若对压缩隐向量加 RoPE，推理时就无法把上投影矩阵吸收进 Q 侧。DeepSeek 的解法是**解耦 RoPE**——K 拆成"低秩压缩部分（不带位置，512 维）+ 独立携带 RoPE 的共享键（64 维）"，后者单独缓存。

**追问**：解耦 RoPE 的代价？→ KV Cache 每 token 每层多存 64 维；实现上 Q/K 都要拼接触带位置的分量，算子更复杂。

**关联**：[[/docs/llm/mla-multi-head-latent-attention.md]]、[[/docs/llm/attention-variants-mha-mqa-gqa.md]]

### Q18. 手撕：写一个 RoPE（白板 10 分钟）⭐⭐⭐

> **速答**：三步——预计算 $\theta$ 矩阵（位置 × 频率外积）→ 把 Q/K 按相邻两维分组旋转 → 旋转后再做标准注意力。考点：旋转只加在 Q/K、相邻对 $(x_1, x_2)$ 的旋转公式、cos/sin 的缓存复用。

```python
import torch

def rope_angles(seq_len, dim, base=10000.0):
    freq = 1.0 / (base ** (torch.arange(0, dim, 2) / dim))   # (dim/2,)
    pos = torch.arange(seq_len)                              # (seq,)
    return torch.outer(pos, freq)                            # (seq, dim/2)

def apply_rope(x, theta):
    # x: (B, h, T, d)；theta: (T, d/2)
    x1, x2 = x[..., 0::2], x[..., 1::2]                      # 相邻两维成对
    cos = theta.cos()[None, None]                            # (1,1,T,d/2)
    sin = theta.sin()[None, None]
    r1 = x1 * cos - x2 * sin                                 # 旋转公式
    r2 = x1 * sin + x2 * cos
    return torch.stack([r1, r2], dim=-1).flatten(-2)         # 交错还原
```

**必答追问**：为什么 cos/sin 要按位置预计算而不是每次现算（decode 时每步只需当前位置的角）；KV Cache 里存的是**旋转后**的 K（所以 decode 只需对当前 token 的 Q/K 旋转）。

## 五、一页速记表（考前扫）

| # | 题目 | 一句话答案 |
|---|------|-----------|
| Q1 | 为什么需要位置编码 | 自注意力置换不变，对顺序无感 |
| Q2 | 正余弦设计动机 | 多频 sin/cos：无参数、位置唯一、相对位置可线性表示 |
| Q3 | embedding 与 PE 为何能相加 | 同维零成本；concat+线性 ≡ 分别投影相加；值域有界不淹语义 |
| Q4 | 绝对 vs 相对 | "第几个" vs "离多远"；语言靠相对关系，外推只能靠相对 |
| Q5 | 可学习 PE 缺点 | 查表止于训练长度，零外推，参数随长度涨 |
| Q6 | RoPE 原理 | Q/K 分块旋转，$R_m^\top R_n=R_{n-m}$，内积只含相对距离 |
| Q7 | 为何不旋转 V | 位置只管"谁跟谁匹配"，不管"内容是什么" |
| Q8 | RoPE 为何主流 | 相对语义 + 零参数 + 兼容工程优化 + 插值外推上限高 |
| Q9 | 远程衰减 | 初始化下的期望衰减偏置，训练可重塑，非硬约束 |
| Q10 | 直接外推为何崩 | 低频维相位进入训练未见区间，logits 分布漂移 |
| Q11 | PI 原理与代价 | 位置线性压回训练区间；代价是局部分辨率下降 |
| Q12 | NTK 原理 | 改 base 不改位置：高频外推、低频内插，压力平摊（进制转换视角） |
| Q13 | YaRN 改进 | 按波长分组插值 + 注意力温度修正，微调成本降 10 倍 |
| Q14 | 调大 base | 频率整体降低、波长拉长；须配合继续训练（LLaMA-3: 5e5） |
| Q15 | 高低频分工 | 高频管局部、低频管远程；外推方法本质是调和这对矛盾 |
| Q16 | RoPE vs ALiBi | 乘法旋转 vs 加法线性偏置；RoPE 外推上限高且主流 |
| Q17 | 与 GQA/MLA 兼容 | GQA 天然兼容；MLA 需解耦 RoPE（独立 64 维位置键） |
| Q18 | 手撕 RoPE | 预计算角度 → Q/K 成对旋转 → 标准注意力；cache 存旋转后的 K |
